🛡️ gpx-scan

A static security analyzer for your `gpx` environment. 

`gpx-scan` helps keep your system safe by reading the source code of the applications you download and flagging suspicious, hidden, or potentially dangerous code patterns (like `eval`, `base64` obfuscation, and unauthorized system calls).

there are also a lot of other things here such as a password protector reseter etc
## Installation
```bash
gpx plugin install your-username/gpx-scan
